# CS-210-Portfolio: Chada Tech Clocks 
## Project Summary

For this project, I made a C++ program for Chada Tech that shows a 12-hour clock and a 24-hour clock at the same time. The user enters a starting time and can choose to add an hour, minute, or second using the menu. Both clocks update when the time changes. The goal was to make a program that was easy to use and showed the time in both formats.

## What I Did Well

I think I did a good job organizing my code and getting the clock to work. I used a class to keep track of the hours, minutes, and seconds, and I broke the program into different functions. I also added comments to help explain what the code does. This helped keep everything organized and easier to understand.

## Where I Could Improve My Code

I could improve my code by making it handle incorrect input better. For example, if someone types letters instead of numbers, the program could handle that without having problems. I could also test more starting times to make sure everything works correctly. This would help make the program work better and prevent errors.

## Challenges and How I Overcame Them

One of the harder parts was figuring out how to make the time change correctly when the seconds or minutes reached 60. I had to make sure the next part of the clock updated when that happened. I used separate functions for the hours, minutes, and seconds to help keep the code organized. I worked through the code and used what I learned in class to help me figure it out. If I get stuck on future projects, I can use my course materials, look up C++ information, and use debugging tools to help me.

## Transferable Skills

This project helped me get more practice with C++, classes, functions, loops, and if statements. I can use these skills in my future programming classes and other projects. I also learned that breaking a program into smaller parts makes it easier to work on instead of trying to do everything at once.

## Making the Program Maintainable, Readable, and Adaptable

I separated my program into three files: main.cpp, Clock.cpp, and Clock.h. Each file has its own purpose, which helps keep the code organized. I also used comments and named my functions based on what they do. This makes it easier to understand the code and go back to change something if I need to. I learned that it is important to make sure the code works, but it also needs to be organized so it is easier to fix or update later.
